# IFAM-dados (repositório privado)

Aqui ficam as planilhas exportadas do Tesouro Gerencial. **Este repositório precisa ser privado**:
as planilhas têm o CPF completo dos estudantes.

Para atualizar o site, envie a planilha para a pasta `dados/<ano>/` (veja o passo a passo em
`COMO-ATUALIZAR.md` no repositório do site). Em cerca de 2 minutos o site mostra os dados novos.

- Aba **Actions**: mostra cada atualização. Verde = publicada; vermelho = algo errado na planilha
  (clique para ler a mensagem; o site continua com os dados anteriores).
- Se você receber um e-mail do GitHub dizendo que a atualização falhou, é esse o motivo.
